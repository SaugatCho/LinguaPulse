# LinguaPulse
LinguaPulse, A Japanese learning webpage 
[Click Here to Learn](https://SaugatCho.github.io/LinguaPulse/)


## Project files

- `index.html` — learning page structure and Japanese learning content
- `style.css` — page layout and responsive styling
- `app.js` — navigation, kanji cards, vocabulary search, and speech features
- `manifest.json` — app name, launch path, and theme metadata
- `favicon.svg` — LinguaPulse icon
- `.nojekyll` — keeps GitHub Pages from running Jekyll processing

The page may use browser-provided Japanese text-to-speech and an external Google Fonts stylesheet. The manifest is metadata only; there is no service worker or guarantee of offline installation.
